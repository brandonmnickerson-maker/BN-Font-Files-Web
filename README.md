# BN Font Files Web

Restricted WOFF2 webfont subsets used by the interactive type tools on [bnicks.com](https://www.bnicks.com).

These files contain only basic printable characters for on-site previews. They are not retail fonts and are not licensed for download, installation or use. To license BN fonts, visit [bnicks.com/shop](https://www.bnicks.com/shop).
